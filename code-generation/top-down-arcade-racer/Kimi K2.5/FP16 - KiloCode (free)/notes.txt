- Developed using Kilo Code

- The Free Kimi K2.5 in Kilo Code performed really well, with very rare tool call failures and generated tokens vfery quickly

- It took quite long to finish the implementation compared to models like MiniMax M2.5 and GLM 5
- The resulting game has wonky physics and controls but is somewhat functional, and the collision system is not bad. It even implemented reverse correctly
